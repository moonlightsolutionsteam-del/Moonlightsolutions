# Wedding Invitation

A static, mobile-friendly wedding invitation page by Moonlight Solutions.

- Edit `config.js` to set names, date, venue, events, schedule and RSVP email.
- Open `index.html` in a browser, or host the folder on any static host (Vercel, Netlify, GitHub Pages).
- Features: countdown, event cards, order of the day, map link, add-to-calendar (.ics), RSVP form (opens the guest's email app).
