# Wedding planning documents

Printable documents for Nadeem & Dariya's wedding (20–21 January 2027, Greenwood Resort, Bengaluru). This folder is not part of the website.

| File | What it is |
|---|---|
| `Signage-Plan.pdf` | Where each sign goes, with sizes and quantities (4 pages) |
| `Signage-Print-Pack.pdf` | Every sign, ready to print (64 pages) |
| `Nadeem-Dariya-Couple-Itinerary.pdf` | The couple's own timeline: outfit changes, photo sessions, shot list, ritual checklists (8 pages) |
| `Groom-Side-Packing-Checklist.pdf` | What the groom's side packs into the car (4 pages) |

The guest guide given to guests is in `wedding-invitation/share-kit/guest-guide.pdf`.
